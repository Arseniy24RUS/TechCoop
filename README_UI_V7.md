# TechCoop.AI UI v7

UI v7 добавляет две отдельные пользовательские страницы к релизному dashboard:

1. `app/techcoop_map_v7.html` — **Карта кооперации 2.0**:
   - четыре ролевые колонки;
   - карточки организаций с названиями, регионами и score;
   - ribbon-связи между компаниями;
   - выбранная связка, легенда и полный paginated-список по роли.
2. `app/techcoop_passport_v7.html` — **Паспорт компании**:
   - поиск по названию, ИНН, ОГРН, региону и ОКВЭД;
   - роли, финансы, evidence ladder и конкретные записи источников;
   - OSM-карта при наличии координат и ссылка на поиск OSM без координат.
3. `app/techcoop_ui_v7.html` — единая страница с картой и паспортом.

## Static Data Layer

`data/v7_static/` — GitHub Pages-compatible JSON layer:

- 2 223 861 базовых профилей компаний;
- 558 373 компании с рассчитанными ролями;
- 8 670 enterprise-профилей с resolved-названиями;
- ГИСП, реестр ПО, патенты/РИД, вакансии и закупки в нормализованном виде.

Данные догружаются лениво: первый экран использует компактный `data/techcoop_ui_v7_payload.js`, а полный поиск/паспорт/списки ролей обращаются к shard-файлам `data/v7_static`.

## Identity Policy

Интерфейс не придумывает названия компаний. Если resolved identity отсутствует, показывается `Профиль расчётной базы`, ИНН/ОГРН и явная пометка, что название не найдено в текущем публичном identity-слое.

## Browser Support

Релиз не требует backend. Для корректной работы lazy-loading JSON shards страницу нужно открывать через GitHub Pages или любой обычный static file server.
